🚀 SETUP (3 STEPS - TAKES 2 MINUTES)

STEP 1: Update Database
------------------------
Open Command Prompt/PowerShell and run:

mysql -u root -p voter_db < update_voters_table.sql

(Enter your MySQL password when asked)


STEP 2: Start Server
---------------------
node index.js

You should see:
┌────────────────────────────────────────────────────────────────┐
│ 🚀 Server Started Successfully!                                │
│ 📡 Server listening on http://localhost:8080                   │
│ 📱 OTP Mode: CONSOLE (No SMS API required)                     │
│ 💡 OTP will be printed in this console when requested          │
└────────────────────────────────────────────────────────────────┘


STEP 3: Test Registration
--------------------------
1. Open: http://localhost:8080/register.html

2. Fill form:
   Voter ID: test123
   Mobile: 9876543210
   Password: Test@1234

3. Click "Send OTP"

4. 👀 LOOK AT YOUR SERVER CONSOLE - You'll see:
   ┌────────────────────────────────────────────────────────────┐
   │ 📱 OTP GENERATED FOR MOBILE NUMBER: 9876543210             │
   │ 🔐 OTP CODE: 456789                                        │
   │ ⏰ VALID FOR: 5 minutes                                    │
   └────────────────────────────────────────────────────────────┘

5. Also check BROWSER ALERT - OTP will show there too!

6. Enter the OTP in the form

7. Complete registration ✅


📊 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When user clicks "Send OTP":
  ↓
Backend generates 6-digit random code
  ↓
Prints OTP in 3 places:
  1. Server Console (terminal)
  2. Browser Alert (popup)
  3. Browser Console (F12)
  ↓
User enters OTP from any source
  ↓
Backend verifies OTP
  ↓
Registration completes! 🎉

A: Check the terminal where you ran 'node index.js'

A: Run the update_voters_table.sql script first
