# Documentation Folder

This folder contains all the documentation and guides for the Decentralized Voting System project.

## 📚 Documentation Files

### Quick Start
- **START_HERE.txt** - Visual quick-start guide with ASCII art for getting started

### OTP Authentication Guides
- **OTP_SETUP_CONSOLE_MODE.md** - Complete setup guide for console mode OTP (development/testing)
- **OTP_SETUP_GUIDE.md** - Comprehensive guide with SMS gateway integration options
- **OTP_QUICK_START.md** - Quick reference guide for OTP functionality
- **OTP_IMPLEMENTATION_SUMMARY.md** - Technical implementation overview

### Implementation Details
- **IMPLEMENTATION_COMPLETE.md** - Final comprehensive summary of OTP implementation
- **CHANGES_SUMMARY.md** - Technical details of all code changes made

---

## 🚀 Quick Reference

**To run the project**, see the main `Project_Details.md` in the root folder.

**For OTP testing**, start with `START_HERE.txt` or `OTP_SETUP_CONSOLE_MODE.md`.

**For production SMS setup**, refer to `OTP_SETUP_GUIDE.md`.
